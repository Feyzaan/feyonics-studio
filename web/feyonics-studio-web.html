How detection works

Studio sends KM HELLO. A macro pad answers with protocol 1, a MIDI pad with protocol 2 and its setup size. You never choose the editor yourself.

Making a MIDI port to send into

Windows 11: install Windows MIDI Services and add a loopback pair named "Feyonics Pad" in its settings.
Windows 10 (or if unsure): install loopMIDI (free), press + once to add a port named "Feyonics Pad". Leave loopMIDI running.
Then pick that port under Bluetooth bridge and choose the same port as the MIDI input in your music app.

Limits of the web version: Chrome or Edge only, the tab has to stay open, Studio does not start with Windows, and only one app can hold the pad's USB port at a time.
